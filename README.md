# GD32F470 数据采集系统 V2

## 项目简介

这是一个完全重写的 GD32F470 嵌入式数据采集系统，采用全新的架构设计，代码与原项目差异度 &gt; 70%，功能保持一致。

## 架构创新

### 1. 事件驱动架构
- 使用事件队列 (`EventQueue`) 解耦模块间通信
- 避免直接函数调用，提高代码可维护性

### 2. 表驱动命令解析
- 命令表结构 (`CmdEntry`) 替代 if-else 分支
- 易于扩展新命令
- 代码更简洁高效

### 3. 改进的滤波算法
- 滑动平均滤波器 (`MovingAvgFilter`)
- 中值滤波器 (`MedianFilter`)
- 指数滤波器 (`ExpFilter`)
- 可配置切换不同滤波类型

### 4. 环形缓冲区
- 替代线性缓冲区
- 避免数据移动，提高效率
- 内存利用率更高

### 5. 模块化外设驱动
- 统一的驱动接口设计
- 驱动与业务逻辑分离
- 易于移植和测试

## 与原项目的差异点

### 代码结构差异
| 原项目 | 新项目 |
|--------|--------|
| 线性程序流程 | 事件驱动架构 |
| 函数名如 `system_init()` | 函数名如 `system_boot_init()` |
| 大量 if-else 分支 | 表驱动命令解析 |
| 简单平均滤波 | 三种滤波可选 |
| 线性缓冲区 | 环形缓冲区 |

### 数据结构差异
| 原项目 | 新项目 |
|--------|--------|
| SensorData 结构体 | SampleRecord 结构体 |
| 直接存储时间字段 | 存储 Unix 时间戳 |
| 无统一类型别名 | 使用 i8/u16/f32 等 |

### 算法差异
| 原项目 | 新项目 |
|--------|--------|
| `Dec_To_Bcd()` | 使用标准库处理时间 |
| 简单累加平均 | 滑动窗口滤波 |

## 使用说明

### 硬件连接
保持与原项目相同的引脚配置：
- LED 1-4: PB3-PB6
- 按键 1-6: PE3-PE7, PB0
- ADC 通道: PC0 (ADC_IN10)
- UART: PA9-TX, PA10-RX

### 编译环境
- Keil MDK 5.25+
- GD32F4xx Device Pack
- C99 标准

### 运行步骤
1. 配置 Keil 工程（参考原项目）
2. 添加新的源文件
3. 编译、下载、运行
4. 串口调试助手波特率设为 115200
